Four Lucid diagrams, one outline each. The outline is the source; the Lucid doc is
built from it. Edit the outline first, then rebuild the diagram.

| # | Outline | Shows |
|---|---|---|
| d1 | [d1-overview-sketch.md](d1-overview-sketch.md) | Every system the extension talks to, and what flows between them |

Outline format: the tech-case-engine `draft-diagram-sketch` schema (Lucid target).
Each outline lists its source files; a label that cannot cite a file does not belong
on the diagram.

**This repository is public.** Labels name public repositories and public Adobe
services only. Internal services appear by role ("the data installer service"),
never by repository or host.
