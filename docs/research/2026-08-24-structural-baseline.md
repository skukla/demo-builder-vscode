## Method / controls

- Function/complexity/export/import counts come from the TypeScript AST; pattern hits from regex over production source; test LOC from raw line counts under `tests/`.
- Type-only imports are excluded from coupling counts, matching the SOP.
- Orphan detection resolves `@/` aliases and relative imports only; a file reached exclusively via a dynamic import with a computed specifier would be a false positive here.
- Imports from tests/ are NOT counted as incoming: a src file used only by tests appears in the orphan list. That is deliberate — production code whose only consumer is a test is a finding, not noise.
- Re-run: `BASELINE_COMMIT=$(git rev-parse --short HEAD) node scripts/measure-structure.mjs > docs/research/<date>-structural-baseline.md`
