# Test Commands Cheat Sheet

## 🚀 Quick Commands

```bash
# 🏆 BEST: Watch mode (5-10s iterations)
npm run test:watch -- tests/features/my-feature

# ⚡ Fast full validation (~20s, measured 2026-08-13)
npm run test:fast

# 🎯 Changed files only (30s-2 min)
npm run test:changed

# 📁 Single file (5-10s)
npm run test:file -- tests/path/to/file.test.ts
```

## 📊 Speed Comparison

| Command | Time | Use Case |
|---------|------|----------|
| `npm run test:watch` | 5-10s | Active dev (BEST) |
| `npm run test:file` | 5-10s | Single file |
| `npm run test:changed` | 30s-2min | Pre-commit |
| `npm run test:fast` | 3-5min | Quick validation |
| `npm test` | 2-3min (cached) | Full suite |

## 💡 Daily Workflow

```bash
# Terminal 1
npm run watch

# Terminal 2
npm run test:watch -- tests/features/your-feature
```

Write code → See results in 5-10 seconds → Iterate

## 🎮 Watch Mode Commands

Once in watch mode, press:
- **`p`** - Filter by file path
- **`t`** - Filter by test name
- **`a`** - Run all tests
- **`f`** - Run failed tests only
- **`q`** - Quit
