## 1. Narrow the unquoted-variable hook to values that can actually hold several words

Kind: hook. Decision: accept.

The zsh word-split rule in .claude/hooks/rules blocks safe commands. A variable set to a literal path with no spaces (B=.claude/skills/backlog-item/backlog.mjs; node $B, W=/path; cd $W) cannot split. An unquoted $(...) in `for f in $(git diff --name-only ...)` IS split by zsh, so that is safe too. Only block a variable assigned from a command substitution (or one holding whitespace) that is later expanded unquoted. Add rule tests for both the blocked and the allowed forms.
