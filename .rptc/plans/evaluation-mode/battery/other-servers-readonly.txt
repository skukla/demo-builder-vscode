# Read-only tools from the OTHER MCP servers a real project carries.
#
# A project's .mcp.json has four servers: demo-builder, commerce-extensibility,
# playwright, dropins. The battery used to allow only demo-builder, so every
# "the agent went around us" result was measured in a world where our tools were
# the only option — and the conclusion drawn from it (AI-1b: discoverability is
# not the constraint) had never been tested against the surface an agent has.
#
# Enumerated live from each server on 2026-08-26 via MCP tools/list, not guessed.
#
# WHY NOT ALL OF THEM. The allowlist's other job is keeping destructive tools out
# of an unattended run. commerce-extensibility ships `aio-app-deploy`; playwright
# ships `browser_run_code_unsafe`. Widening the surface must not widen that.
# Same read-only rule as the rest of the battery, applied per tool.

# upload-chat-history — all deploy, mutate config, authenticate, or send data out.
