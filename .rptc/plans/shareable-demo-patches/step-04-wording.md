# Step 04 — Say what the extension writes

Replace "This storefront's owner controls its code; Demo Builder does not change it." with a
sentence that is true: Demo Builder adds the pieces that connect the storefront to the demo
(the product-page fallback, block libraries, the content and store settings, the description
file) and leaves the storefront's own code alone unless the SC accepts a fix. The card line
for the boilerplate: "Built on Adobe's Commerce boilerplate 4.0.1; Demo Builder's current one
is 6.0.0. N of Demo Builder's fixes fit this code." Copy reviewed with the owner before it
ships; pinned by the caveat tests.
