Integrations

Why a calm list here, not a grid

  • contextThis is mid-wizard, in a narrow column beside the summary — a wide card grid would collapse to 1–2 columns and read like a second dashboard. A single-column list fits the frame.
  • pre-deployNothing is deployed yet, so there's no live status / URL / redeploy to show. Each row is just identity: name · kind · APIs it will provision · edit/remove. Deploy happens at build.
  • sharedDestination shown once at the top (co-tenants of one workspace), not repeated per row like the current design.
  • detailEdit/detail opens the existing Add-Integration modal — no new drawer; the wizard already has enough chrome.
  • laterThe live status grid + detail drawer is a separate dashboard surface (the other prototype) for the deployed project — downstream, gated on ADR-011 D3.
